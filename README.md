# 画画乐园

一个专为儿童设计的趣味绘画 Web 应用（3-8 岁），支持描边填色和自由画布两种模式，
内置 70+ 描边形状（含汉字描红）、21 类 138 个卡通贴纸和 8 种创意画笔。纯本地运行，
无广告、无外链、不收集任何数据，支持 PWA 离线使用。

## 功能特色

### 描边填色（逐笔引导描红）
- **71 个形状**，六大分类按难度分级：基础 / 汉字 / 数字 / 字母 / 动物 / 交通
- **逐笔引导**：当前笔高亮，描完自动解锁下一笔（汉字按笔顺描红识字）
- **覆盖判定**：每一笔真实描够 90% 才通过，跳笔蒙混无效
- 形状图鉴：完成打 ✓、收集进度、难度星级、一键打印本分类涂色页
- 描完自动收入"我的作品"，集齐一个分类触发专属庆祝
- 填色阶段调色盘 20 色，涂满 70% 触发庆祝动画

### 自由画布
- **8 种拟真画笔**：彩笔（纸面颗粒质感）、马克笔（方头宽笔叠色）、毛笔（随速度变化的笔锋）、荧光笔（宽扁半透明）、彩虹笔、喷雾、发光笔、虚线笔——每种笔刷配专属摩擦音效（蜡笔沙沙像素描纸、马克笔顺滑、喷雾嘶嘶）
- **27 个几何图形**：基础（圆/椭圆/多边形/梯形等 12 个）+ 趣味（星/月牙/水滴/宝石/雪花等）+ 符号（箭头/气泡/音符/闪电/十字），放置后可用填充工具涂色
- **对称万花筒画**：一键切换 左右对称 / 四向对称 / 万花筒（12 镜像），随手一画就是漂亮图案
- **画画场景**：海底 / 太空 / 草地 / 雪地 卡通场景底图，配合贴纸编故事；橡皮擦只擦笔迹不伤场景
- **21 类卡通贴纸（134 个 AI 生成透明 PNG + 4 个 SVG 兜底）**：伙伴、小鸡一家、童话、玩具、甜点、海洋、恐龙、太空、音乐、水果、天气、运动、节日、交通、动物、花园、美食、表情、职业、生日、怪兽
- **小画家任务**：🏆 10 个线性任务（放贴纸/换场景/旋转复制/万花筒/保存作品…），完成撒花庆祝，家长中心可看创作小报告
- **贴纸玩法**：放好的贴纸点选后可放大/缩小/旋转/复制/删除（操作条按钮），iPad 双指捏合缩放旋转、桌面滚轮缩放；「最近」贴纸分类快速回找常用
- 撤销（40 步，缩放/旋转连按自动合并一条）、清空二次确认、画布底色切换、无限画布拖动
- 儿童友好大色板（20 色大圆钮网格，好点好选），一键保存作品

### 作品贺卡 & 灵感骰子
- **作品贺卡**：任意作品做成贺卡——5 种贴纸风边框（彩旗/爱心/星空/花环/雪花）+ 祝福语，存回作品集或保存图片打印
- **灵感骰子**：🎲 不知道画什么就摇一条创作点子（场景 × 贴纸 × 画笔组合灵感）

### 我的作品
- 作品画廊（缩略图 / 名称 / 日期），大图预览
- IndexedDB 持久存储（上限 200 张、PNG 原画质 + 360px 缩略图），旧版本 localStorage 数据自动迁移
- 保存到设备、系统分享（Web Share）、删除二次确认
- 家长中心「备份全部作品」：一键打包 ZIP（含作品清单 manifest.json）下载留存

### 家长中心（长按首页右上角齿轮 + 算术门）
- 音效开关、护眼提醒（连续玩耍 20 分钟提示休息）
- 备份全部作品（ZIP）、清空作品集 / 重置收集进度、关于页

## 技术栈

- 纯前端实现：HTML5 Canvas + CSS3 + Vanilla JavaScript（零依赖、零构建）
- 作品持久化：IndexedDB（容量大，PNG 原画质 + 缩略图双份存储；`file://` 直开等场景自动回退 localStorage）
- AI 生成 PNG 贴纸（调色板量化优化）+ SVG 兜底贴纸 + 程序化形状库（含笔画分解汉字/字母工厂）
- PWA：manifest + Service Worker，添加到主屏幕后离线可用
- 自托管子集字体（85KB woff2），真·零外链
- Node.js 静态服务器（可选，支持 gzip / ETag），用于局域网访问
- 行为测试守卫（GitHub Actions 自动运行）

## 快速开始

### 方式一：直接打开

双击 `index.html` 即可在浏览器中使用。

### 方式二：本地服务器（推荐用于 iPad）

```bash
# 启动服务
./kids-draw.sh start

# 查看状态
./kids-draw.sh status

# 停止服务
./kids-draw.sh stop

# 重启服务
./kids-draw.sh restart
```

启动后访问 `http://localhost:3000`，iPad 等设备通过 `http://<本机IP>:3000` 访问。

### 方式三：添加到主屏幕（推荐）

iPad 打开应用后 → 分享 → 添加到主屏幕，即可像原生 App 一样全屏离线使用。

## 项目结构

```
kids-draw/
├── index.html          # 主页面（三场景 + 弹层）
├── manifest.json       # PWA 清单
├── sw.js               # Service Worker（离线缓存）
├── server.js           # Node.js 静态文件服务器（gzip/ETag）
├── kids-draw.sh        # 服务启停脚本
├── css/style.css       # 样式
├── js/
│   ├── app.js          # 应用主控（场景/音频/颜色转盘）
│   ├── shapes.js       # 形状库（71 个：多部件笔画分解工厂）
│   ├── stickers.js     # 贴纸库（21 类，134 个 PNG + 4 个 SVG 兜底）
│   ├── missions.js     # 小画家任务（10 个线性任务 + 进度持久化）
│   ├── tracing.js      # 描边填色（逐笔引导 + 覆盖判定 + 图鉴/打印）
│   ├── freecanvas.js   # 自由画布（画笔/贴纸/撤销/保存）
│   ├── store.js        # ArtworkStore / ShapeProgress / Settings
│   ├── gallery.js      # 我的作品（画廊/分享）
│   ├── card.js         # 作品贺卡工坊（5 种边框 + 祝福语合成）
│   └── parent.js       # 家长中心（算术门/护眼提醒）
├── assets/
│   ├── fonts/          # 自托管子集字体（OFL）
│   ├── icons/          # PWA 图标
│   └── stickers/       # 贴纸 PNG 素材（21 类 134 个，512×512 透明底）
└── tests/
    └── behavior.test.js
```

## 运行环境

- 现代浏览器（Chrome / Safari / Firefox / Edge），iPad / 触屏设备优先
- Node.js >= 12（仅服务器模式需要）
