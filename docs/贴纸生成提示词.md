# 贴纸素材生图提示词包（image2.5）

> 目标：用 AI 生图模型批量生成与 App 画风一致的贴纸素材，替换/扩充现有 13 类程序化 SVG 贴纸。
> 用法：每条提示词 = 「主体描述」+「全局风格锚点」。本文档给出全部主体清单，替换进模板即可。

---

## 一、全局风格锚点（每条提示词末尾必带）

```
儿童贴纸插画，扁平矢量风格，深棕色粗描边，高饱和糖果色，圆润Q版造型，
大头小身比例，简单微笑表情带粉色腮红，主体配色不超过4种，
纯白背景，单个主体居中，主体占画面80%，无渐变，无阴影，无复杂纹理，无文字，无水印
```

要点说明：

- **深棕色粗描边**：与 App 全局描边色一致（#5D4037），保证贴纸放在任何底色画布上都有轮廓
- **配色不超过 4 种**：主体色 + 描边 + 腮红 + 点缀，太杂会破坏糖果感
- **无渐变无阴影**：现有 SVG 全是平涂色块，AI 生成若带渐变/体积阴影会明显违和
- **透明底**：若模型支持直接输出透明背景 PNG，把「纯白背景」换成「透明背景」；不支持则白底生成后抠图

## 五、一致性与效率技巧

1. **先出风格样张**：任选一个主体生成 4 张，挑最满意的一张作为「风格参考图」；image2.5 若支持图生图/风格参考，后续全部以它为基准
2. **同批生成**：同一分类的主体放在同一批生成，风格离散度最小
3. **固定参数**：尺寸固定 1024×1024；支持种子的模型固定种子前缀，仅改主体词
4. **逐张验收**：对照风格锚点检查——描边是否深棕、是否误加渐变阴影、是否出现文字；不合格换词重出（常见干扰词：把「贴纸」单独写容易被理解成带白边的贴纸裁切，若不想要白边就别在主体段用"贴纸"二字，只用结尾风格段里的"贴纸插画"）
5. **白边变体**（可选）：若想要更"实体贴纸"的感觉，在风格锚点里把「纯白背景」换成「主体外围一圈白色刀版描边，透明背景」——注意这会与现有 SVG 贴纸风格略有差异，建议全库统一二选一

## 六、技术规范与入库

- **尺寸**：生成 1024×1024，导出 **512×512 PNG**（画布上最大档贴纸显示约 240px，2x 屏依然清晰）
- **背景**：透明底最佳；白底需抠图后导出 PNG（不要 JPEG，会有白边）
- **命名**：与现有 id 风格一致（全小写英文拼音/英文），如 `assets/stickers/ocean/dolphinkid.png`
- **入库**：`StickerLibrary.items` 中把对应条目换成 PNG 引用即可，其余逻辑（预载/渲染/面板）自动生效：

```js
// 原来（SVG 程序化生成）
{ id: 'dolphinkid', name: '小海豚', assetType: 'svg', source: makeStickerSvg('#74B9FF', 'dolphin') },
// 替换为（AI 生成 PNG）
{ id: 'dolphinkid', name: '小海豚', assetType: 'png', source: 'assets/stickers/ocean/dolphinkid.png' },
```

- **新增分类**：在 `categories` 里加一行（如 `vehicles: { label: '交通工具', stickers: [...] }`），自由画布贴纸弹层的分类 tab 会自动出现
