# iPad 真机测试清单

> 所有自动化验证均在无头 Chrome（桌面模拟）完成。上架/分发前请用真机过一遍以下清单，
> 重点确认 iOS Safari 的触摸、音频与性能表现。建议 Safari 直接访问 + "添加到主屏幕" 各测一轮。

## 准备

- [ ] iPad 与服务器同一局域网，Safari 打开 `http://<本机IP>:3000`（或 Cloudflare Pages 线上地址）
- [ ] "添加到主屏幕"，确认出现星星图标、全屏独立窗口启动（无 Safari 地址栏）

## 首页与导航

- [ ] 三张卡片（描边填色 / 自由画布 / 我的作品）点击进入对应场景
- [ ] 右上角齿轮单击无反应，长按约 1 秒进入算术门
- [ ] 横屏 / 竖屏切换：布局不破、画布内容不丢

## 描边填色

- [ ] 顶部形状名按钮（如"圆形 ▾"）打开形状图鉴，5 个分类 tab 可切换
- [ ] 选择"字母 A"等新内容，虚线轮廓正常显示（多笔字形无内部杂线）
- [ ] 沿虚线描完一笔后只有该笔变绿，其他笔仍是虚线
- [ ] **描 3 笔跳过 1 笔 → 提示"再多描一点点"，不进入庆祝**（覆盖判定）
- [ ] 全部笔画描完 → 庆祝动画 + 彩纸下可见完整成品 + 自动保存
- [ ] 填色阶段调色盘完整可见、可换色（此前修过的出屏 bug）
- [ ] 填色 ≥70% 自动庆祝并 3 秒后切下一个形状
- [ ] 起点橙色圆点在落笔后停止跳动

## 自由画布

- [ ] 8 种画笔逐一切换涂画，彩虹笔/发光笔/喷雾效果正常
- [ ] 撤销按钮逐笔回退，清空需点两次，返回单击生效
- [ ] 贴纸弹层：13 分类浏览、选择、放置；贴纸点两下删除、按住拖动
- [ ] 图形弹层：选星形/小猫等放置（不再永远是圆形）
- [ ] 颜色转盘弹出/收起正常，选色后画笔立即生效
- [ ] 保存按钮 → "作品已保存"提示 → 我的作品里可见
- [ ] **画到一半把手指拖出画布外再松开，画面不会继续自己画**（指针卡死修复）

## 汉字描红与打印

- [ ] 形状图鉴"汉字"分类 15 个字（一/二/三/十/口/人/八/上/下/工/木/王/五/六/四）轮廓清晰
- [ ] 汉字按笔顺逐笔引导：描完"横"才解锁"竖"（以"十"为例）
- [ ] 图鉴"🖨 打印涂色页"：弹出的打印预览为 A4 双列线稿，适合打印
- [ ] 作品预览"分享"按钮：iPad 弹出原生分享面板，可存照片/发微信

## 我的作品

- [ ] 卡片缩略图、名称、日期显示正常
- [ ] 点开预览 → "保存到设备"下载 / "删除"两次确认
- [ ] 空状态显示引导文案

## 家长中心

- [ ] 音效开关：关闭后绘画/庆祝无声，重启浏览器后仍记住
- [ ] 护眼提醒：关闭开关后不再弹；开启时（可用短时间验证）弹全屏休息倒计时
- [ ] 清空作品集 / 重置收集进度均需两次确认
- [ ] **「备份全部作品 (ZIP)」：点击后下载一个 .zip，解压可见 manifest.json + 全部作品图片（文件名为中文作品名）**
- [ ] 没有作品时点备份 → 提示「还没有作品可导出」，不报错
- [ ] **旧数据迁移**：用 v2.0 及以前版本保存过作品的设备，升级后打开应用 → 作品全部还在（IndexedDB），localStorage 旧键已释放；再保存新作品、重启应用后新旧作品均在

## 安卓 APK（android-app/ 构建产物）

- [ ] 侧载安装（允许"安装未知应用"），桌面出现"画画乐园"图标（自适应图标无白边异常）
- [ ] 启动即全屏 WebView，无地址栏；状态栏底色为应用主题红
- [ ] **飞行模式全程可用**（资源全部内置）：描边、画笔、贴纸、保存作品
- [ ] **返回键**：画布中按返回 → 回首页而非退出；首页按一次提示"再按一次退出"，2 秒内再按才退出
- [ ] **从备份恢复**：在网页版导出 ZIP 传入手机 → 家长中心「从备份恢复」→ 旧作品全部出现在 APK 里
- [ ] 升级安装：新 versionCode 的 APK 直接覆盖安装 → 作品与进度仍在（同签名）

## 音频与性能

- [ ] 首次触摸后绘画有沙沙声（iOS 音频解锁）
- [ ] 静音拨片状态下全程无声
- [ ] 连续涂画 3-5 分钟无明显发热/掉帧；描边字体（站酷快乐体）正常显示
- [ ] 飞行模式（离线）下从主屏图标打开，应用完整可用（PWA 离线缓存）
